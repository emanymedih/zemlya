# Task 6 — иерархия ОКТМО Калужской области

Статус: реализация и live-проверка 2026-09-27.
Источник: Росстат, набор `7708234640-oktmo`, структура
`https://rosstat.gov.ru/opendata/7708234640-oktmo/structure-20260210T1102.csv`.

## Контракт

- `TER` — код региона; `KOD1` — муниципальный округ/район/городской округ;
  `KOD2` — городское/сельское поселение; `KOD3` — населённый пункт.
- `RAZDEL` — раздел, а не тип объекта. Для родителя используем запись
  раздела 1 с точным кодом из компонентов. Раздел 2 содержит записи и
  группирующие заголовки населённых пунктов.
- Связь `oktmo_parent_code` означает иерархию кодов официального набора.
  Она не устанавливает юридическую границу или адрес участка.
- Даты `DateUtv` и `DateVved` — принятие и введение. Они не задают
  временной интервал действия; история перекодировки относится к Task 7.

## Проверки перед публикацией

1. Сверить `TER` каждой выбранной строки с целевым субъектом.
2. Определить уровень из `KOD1`/`KOD2`/`KOD3` и раздела; исключить
   невозможную форму кода и населённый пункт в неверном разделе.
3. Выявить дубли ключа записи (код, раздел, даты) и неоднозначных родителей.
4. Для каждого дочернего кода найти ровно одного родителя в разделе 1;
   проверять отсутствие родителя и циклы.
5. Только при нулевых исключениях публиковать отношения с evidence CSV.

Отчёт запуска содержит количества проверенных строк, поуровневые counts,
3281 потенциальное дочернее отношение для текущей выборки, число
разрешённых родителей, циклов и исключения с исходным номером строки.
При ошибке остаётся failed run с raw snapshot, текущий pointer не сдвигается.

## Приёмка

- Unit fixtures: все уровни, пропущенный родитель, дубли, чужой субъект,
  неверная форма, цикл; неизвестная версия структуры блокируется до загрузки.
- Docker suite проходит целиком; реальный strict pipeline на свежем PBF,
  без флага stale, сохраняет 3281 подтверждённое отношение и 0 исключений.
- Повторный запуск сохраняет стабильные доменные ключи/relations;
  `integrity_check=ok`, current pointer указывает на последний success.
- Утверждения о парцеллах, праве доступа и правовых границах не выводятся.
