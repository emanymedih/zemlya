# Roadmap проверки полезности ядра «Земля Радар»

Статус: **PLANNED**, 2026-09-28. Точка старта: Tasks 1–12 прошли местный и
внешний quality gate; данные конкретных участков ещё не подключены.

## Решение, которое проверяем

Первая гипотеза: по известному кадастровому номеру ядро помогает быстрее
подготовить проверяемое предварительное досье участка, показывает
неопределённость и сохраняет ссылки на источник каждого вывода. Решение
пользователя после досье: продолжить проверку, отказаться или запросить
недостающие документы. Юридический вывод о праве проезда и инвестиционная
рекомендация в первую версию не входят.

Массовое обнаружение и рейтинг участков остаются следующим экспериментом.
Первый эксперимент требует меньше данных и допускает ручной ввод официальных
документов при отсутствии пригодного машинного канала. Это даёт возможность
измерить пользу до создания большого реестрового коннектора.

## Этапы и решения

Сроки указаны как ориентиры для одного небольшого пилота; время ожидания
доступа к внешнему сервису учитывается отдельно.

Отобрать 30 реальных кадастровых номеров по географии и типам участков; не выбирать их по заранее известному результату. | Есть номера и законный способ получить эталонные сведения; вопросы действительно влияют на решение о дальнейшей проверке. |

## Предлагаемые пороги пилота

Это **критерии эксперимента**, их следует утвердить до просмотра результатов
30 участков. Выборка мала и не доказывает качество для всей области.

- **Безопасность вывода:** 0 неподтверждённых утверждений о праве, статусе
  участка или гарантированном подъезде. Любой такой случай блокирует
  автоматический вывод до исправления и повторной проверки.
- **Прослеживаемость:** 100% существенных фактов в досье имеют конкретный
  источник, снимок и время получения; 100% отсутствующих данных помечены.
- **Покрытие:** хотя бы 21 из 30 досье содержит минимальные сведения, нужные
  для предварительного решения по заранее утверждённому шаблону. Для
  остальных указывается конкретная причина неполноты.
- **Экономия:** медианное время проверки с досье ниже ручного baseline хотя
  бы на 30% при сопоставимом качестве. Записывать также абсолютные минуты и
  время подготовки/обновления данных.
- **Устойчивость:** повтор того же снимка не создаёт новых фактов;
  изменившийся ответ даёт понятный diff; отказ источника сохраняет последнее
  подтверждённое досье и показывает его возраст.

При пограничном результате увеличить выборку и исправить одну установленную
причину. При отсутствии доступа, низком покрытии или экономии выбрать
ручной режим проверки конкретных номеров. При повторном провале остановить
развитие массового радара.

## Работа с источниками и эксплуатацией

- Разведка Task 13 начинается с официальных условий. Публичная карта и
  пользовательский интерфейс сами по себе не устанавливают право на
  массовые запросы. Не переносить технические URL из браузера в production
  без подтверждённого режима использования.
- Geofabrik служит картографическим контекстом. Пересечение или близость
  дороги описывается геометрически; правовой доступ проверяется отдельно.
  ОКТМО задаёт территориальную привязку и историю кода, без геометрии участка.
- В пилоте запускать обновление по потребности проверки и отдельно измерять
  стоимость одного цикла. Постоянное расписание и массовую загрузку вводить
  после подтверждения пользы. Текущий gate свежести сохраняется: перед
  запуском источник обновляется либо явно фиксируется причина остановки.
- Собирать эксплуатационные метрики: минуты ручной работы, сетевые/платные
  запросы, время Docker run и экспорта, ошибки источника, долю cache hits,
  затраты на разбор изменений схемы. Это войдёт в стоимость досье.

## Доказательства и граница следующего блока

В репозитории сохранить: матрицу источника и прав доступа, шаблон досье,
обезличенный список 30 кейсов и правила отбора, ручной baseline, результаты
слепой сверки, журнал дефектов, затраты, решение go / narrow / stop. Личные
и ограниченные сведения в публичный репозиторий не помещать.

Следующее действие: выполнить этапы 0 и 1 параллельно. Начать код Task 13
после проверки канала и фиксации шаблона досье. Новые слои, интерфейс
массового поиска и рейтинг участков ждут решения этапа 5.
