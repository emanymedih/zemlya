# Task 7 — история и перекодировка ОКТМО

Статус: DONE, реализация и live-проверка завершены 2026-09-28.

Официальный источник: набор Росстата `7708234640-codingtable` —
«Перекодировочная таблица для замены аннулированных кодов ОКТМО
на действующие коды ОКТМО для населенных пунктов субъектов РФ».

## Контракт

- История перекодировки берётся только из отдельной официальной таблицы.
- Даты `DateUtv`/`DateVved` текущего ОКТМО не превращаются в интервалы действия.
- Каждая строка coding table сохраняется как отдельная normalized evidence record.
- Аннулированный и действующий коды представлены стабильными `oktmo_code` entities.
- Прямая замена публикуется как `oktmo_replaced_by`.
- Транзитивная замена по цепочке автоматически не выводится.
- Строка без действующего кода сохраняется как факт аннулирования без relation.
## Проверки

1. Версия структуры должна быть `structure-20231110T1511`.
2. Парсер принимает официальные 8- и 11-значные формы кодов.
3. Пустая строка subject/cancel/change допустима только как продолжение
   предыдущей записи с дополнительным действующим кодом.
4. Суффикс `*` у кода сохраняется как source note и не входит в сам код.
5. Для целевого субъекта код замены должен оставаться в том же субъекте.
6. Точный дубль evidence-строки и цикл перекодировки блокируют публикацию.
7. Source-backed one-to-many замены сохраняются несколькими прямыми relations.

## Приёмка

- Fixture tests покрывают прямую цепочку, one-to-many, отсутствие замены,
  cross-subject ошибку, цикл, continuation rows, короткие коды и source note.
- Полный Docker suite проходит.
- Strict pipeline работает на свежем Geofabrik PBF и актуальных Rosstat datasets.
- Повторный запуск сохраняет стабильные domain IDs/relations и SQLite integrity.
- Machine report сохраняет версии обоих Rosstat datasets и их raw hashes.
